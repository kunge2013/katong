欢迎使用雪漫画

雪漫画是一个 AI 驱动的小说转漫画分镜系统。您可以将网络小说转换为漫画分镜图像。

快速开始

  1. 创建小说 - 导入小说文本或 URL
  2. 清洗文本 - 执行 4 步清洗流水线
  3. 提取资产 - 自动识别角色、场景、道具
  4. 创建项目 - 配置画风和模型参数
  5. 生成分镜 - AI 拆分为漫画分镜
  6. 推导提示词 - 生成图像提示词
  7. 生成图像 - AI 生成漫画分镜图像

API 文档

所有 API 端点以 /api/ 开头，返回 JSON 格式数据。

  • GET /api/novels - 列表小说
  • POST /api/novels - 创建小说
  • POST /api/novels/:id/clean - 清洗小说
  • GET /api/projects/:id/assets - 列表资产
  • POST /api/projects/:id/storyboard/split - 分镜拆分
  • POST /api/scripts/:id/derive - 推导提示词
