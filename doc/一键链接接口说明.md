## 一、功能概述

**一键链接**（asset_link_upload）是雪漫画（CineGacha）应用中的角色资产管理功能，用于：

- 将本地生成的角色立绘/三视图/场景图等上传到云端对象存储
- 生成带签名的可访问URL链接
- 将链接存储在数据库中与角色资产关联
- 为后续分镜推导提供视觉参考URL

## 四、请求参数详解

### 4.1 URL查询参数

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| `X-Amz-Algorithm` | string | 是 | 签名算法 | `AWS4-HMAC-SHA256` |
| `X-Amz-Checksum-Mode` | string | 否 | 校验和模式 | `ENABLED` |
| `X-Amz-Credential` | string | 是 | 凭证信息 (AccessKeyId/日期/区域/服务/请求类型) | `d054cbde.../20260815/auto/s3/aws4_request` |
| `X-Amz-Date` | string | 是 | 请求时间 (ISO8601格式) | `20260815T143000Z` |
| `X-Amz-Expires` | integer | 是 | URL有效期(秒) | `259200` |
| `X-Amz-SignedHeaders` | string | 是 | 参与签名的HTTP头列表 | `host` |
| `X-Amz-Signature` | string | 是 | HMAC-SHA256签名值 | 64位十六进制字符串 |
| `response-content-disposition` | string | 否 | 下载时的文件名 | `attachment; filename="xxx.jpeg"` |
| `x-id` | string | 是 | 操作类型 | `GetObject` |

### 4.2 上传请求参数（推测）

```http
POST /v1/images/upload HTTP/1.1
Host: api.grsai.com
Authorization: Bearer <api_key>
Content-Type: multipart/form-data

参数:
- file: 图片文件 (binary)
- type: "role_portrait" | "role_reference" | "asset"
- novel_id: 小说ID (integer)
- role_name: 角色名称 (string)
- project_id: 项目ID (string, optional)
```

### 4.3 API密钥配置

从数据库 `settings` 表获取：

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `account_pool_grsai_api_key` | `sk-c2c3677cfccf48eaab0c49b056c2a5d8` | GRSai API密钥 |
| `enable_grsai_service` | `true` | 是否启用GRSai服务 |
| `manga_grsai_http_timeout` | `1200` | HTTP超时时间(秒)，约20分钟 |

## 七、业务流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        一键链接业务流程                                   │
└─────────────────────────────────────────────────────────────────────────┘

步骤1: 用户操作
    └── 在角色中心/资产库页面选择资产 → 点击"一键链接"按钮

步骤2: 前端UI层 (cinegacha.ui.role_center_page)
    ├── 获取选中资产的本地图片路径 (image_path)
    ├── 验证文件存在性
    ├── 显示上传进度
    └── 调用核心层上传接口

步骤3: 核心业务层 (cinegacha.core.asset_link_upload)
    ├── 验证图片文件存在且格式合法
    ├── 从settings表读取GRSai API配置
    ├── 构建上传请求参数
    ├── 调用API层执行上传
    └── 接收返回的云端URL

步骤4: API适配层 (cinegacha.api.upload_api)
    ├── 构建multipart/form-data请求体
    ├── 添加Authorization请求头 (Bearer token)
    ├── 发送HTTP POST请求到云存储服务
    ├── 处理响应并提取URL
    └── 异常捕获与错误转换

步骤5: 云存储服务 (Cloudflare R2 via GRSai)
    ├── 接收上传文件
    ├── 生成唯一UUID作为文件名
    ├── 存储到R2存储桶
    ├── 生成带签名的访问URL
    └── 返回URL给调用方

步骤6: 数据持久化
    ├── 将URL写入roles表的role_url字段
    └── 更新updated_at时间戳

步骤7: 结果返回
    ├── UI显示上传成功
    └── 资产列表中显示云端链接状态
```

## 九、安全机制

### 9.1 代码保护

- **加密方式**: PyArmor 加密
- **保护范围**: 所有核心业务逻辑 (`cinegacha/core/`, `cinegacha/api/`)

### 9.2 API安全

- **认证方式**: Bearer Token (API Key)

## 十二、注意事项

1. **URL有效期**: 生成的链接有效期为72小时，过期后需要重新生成
2. **文件格式**: 支持 JPG/PNG 格式图片
3. **文件大小**: 受API超时和云存储限制
4. **网络依赖**: 需要稳定的网络连接才能完成上传
5. **API密钥**: 需要正确配置GRSai API密钥才能使用
